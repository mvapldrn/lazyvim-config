# 💤 LazyVim

My personal [LazyVim](https://lazyvim.org) configuration based on the starter template that can be found here [LazyVim](https://github.com/LazyVim/LazyVim).

## Changed keymappings

I like to use the arrow keys (instead of h,j,k,l) and kitty as terminal. Kitty is my terminal and uses 
the left-control modifier (e.g. Ctrl-Left/Right/Tab to switch between tabs). Movement between stuff inside nvim is changed slightly;

| Key      | Descritpion        | Mode |
|:--------:|:-------------------|:----:|
| S-Left   | Go to left window  | n    |
| S-Right  | Go to right window | n    |
|
